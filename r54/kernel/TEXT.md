# CC 2.7 The kernel: where the normative text is

The normative text of the kernel is section 2.7 (2.7.1 to 2.7.10) of Part 2, "The Grammar", of the CIRIS
constitution: `constitution/part_2_the_grammar.md` in
[CIRISConstitution](https://github.com/CIRISAI/CIRISConstitution). Read it there, at the edition the crate's
CHANGELOG names for the release you are reading.

This file held a verbatim extract of that section (edition 1.0-rc19, commit `60c741e`, lines 1066 to 1253) until
2026-11-25. The extract fell behind the parent and was removed so that there is one copy. A sentence cited as
"TEXT.md" elsewhere in this repository is a sentence of CC 2.7.
